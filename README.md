# ElvUI_LizeUI

## Descripción (CurseForge / Wago)

### Versión corta

**ElvUI_LizeUI** (LizeUI) es un addon para **ElvUI** con el que puedes importar una interfaz **clara, limpia y efectiva** para cualquier tipo de contenido, tanto **PvE** como **PvP**. Incluye perfiles por resolución (**2K/3K**), layouts de **WoW Edit Mode** y presets/integraciones para addons compatibles.

**Para que la interfaz se vea igual**

**Imprescindible**: Plater, BetterCooldownManager, AddOnSkins, Details!

**Recomendado**: HidingBar, Immersion, CursorRing

**Opcional**: Simple Addon Manager

### Versión media

LizeUI es un addon con el que podrás importar todo lo necesario para tener una interfaz clara, limpia y efectiva para todo tipo de actividades, tanto **PvE** como **PvP**.

Nace de la necesidad de ir añadiendo funciones adicionales que, con el tiempo, me di cuenta de que necesitaba. Poco a poco fue creciendo hasta el punto de convertirse en un addon propio, con el objetivo de **unificar** todas estas mejoras en un mismo sitio.

**ElvUI_LizeUI** incluye:
- Importación de perfiles/configuración estilo LizeUI.
- Perfiles específicos por resolución (**2K / 3K**) para mantener **escalado, proporciones y alineación**.
- Layouts de **WoW Edit Mode** (2K/3K).
- Integraciones/imports incluidos para: **Plater**, **Details!**, **BetterCooldownManager** y **WindTools** (si están instalados).
- Utilidades extra de “quality of life” (QoL) dentro del addon.

## Qué hace

**ElvUI_LizeUI** es un addon para **ElvUI** que:

- Importa perfiles/configuración estilo LizeUI.
- Incluye perfiles específicos por resolución (**2K / 3K**) para mantener **escalado, proporciones y alineación**.
- Incluye layout de **WoW Edit Mode** para 2K/3K.
- Ofrece integraciones/imports para addons compatibles (si los tienes instalados):
  - **Plater**
  - **Details!**
  - **BetterCooldownManager**
  - **WindTools**
- Añade pequeñas utilidades “quality of life” (QoL) integradas en el addon.

## Requisitos

- **ElvUI** (obligatorio).

## Cómo instalar

1. Instala/actualiza **ElvUI**.
2. Copia **ElvUI_LizeUI** en `_retail_/Interface/AddOns/`.
3. Entra al juego y aplica el perfil correspondiente a tu resolución (**2K/3K**).
4. Usa `/reload` si es necesario.

## Soporte / Feedback

Si encuentras inconsistencias de escalado o alineación, indica:
- Resolución
- Escala de UI
- Perfil usado (2K/3K)

Con eso será mucho más fácil reproducir el problema.
